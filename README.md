## 🚀 Quick Start

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn package manager

### Installation & Development

1. **Clone the repository**
   ```bash
   git clone https://github.com/ashderkarim123/README.git
   cd README/portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser** and navigate to `http://localhost:5173`

### Build for Production

```bash
npm run build
npm run preview
```

The production build will be created in the `dist/` directory.

## 📝 Customization

All portfolio content can be easily customized by editing:

**`portfolio/src/data/portfolio.ts`**

This file contains all your personal information:
- Name, headline, and contact information
- Social media links
- Projects and their descriptions
- Skills and technologies
- Certifications
- Work experience and timeline
- Statistics and badges

Simply update the values in this file, and the entire portfolio will reflect your changes!
